# loongvpu-kernel-dkms

DKMS sources for the Loongson 2K1000LA's VPU. The SPDX license identifiers in the source files indicate that the module is GPLv2-licensed.

Note: it seems the VPU of 2K1000(LA) is entirely unrelated to that of 2K3000, and the ABI is extremely simple. Hence, the driver is expected to be useless without closed-source userspace blobs, and only serves as a reference regarding the hardware/firmware interface.
